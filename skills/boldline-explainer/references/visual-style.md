# Visual Style Guide (*"Vẽ tay viền đậm"* / Bold-Outline 2D)

Follow these design tokens whenever adding new characters, backgrounds, or props so every scene looks like it belongs to the same universe:

## 1. Line & Stroke Tokens
- **Primary outline**: `#111827` (dark charcoal-black), `4px–7px` width at `720p` scale.
- **Limbs**: Stick-like arms and legs (`7px–8px` stroke) with round skin-tone hands (`#fde6d8`) and black oval shoes.
- **No soft gradients on characters**: Always use flat colour fills.

## 2. Colour Palette
- **Skin**: `#fde6d8` with rosy cheeks (`#fca5a5`).
- **Dark card**: `#1a1c20` background with `#23262c` diagonal spotlight beam.
- **Office wall / floor**: `#ece0be` cream wall, `#8c6d46` baseboard, `#b58453` plank floor with `#7c5530` wood lines, `#a32a29` carpet with `#d4af37` trim.
- **Forest / hills**: `#bae6fd` sky, `#4ade80` rolling hills, `#15803d` / `#166534` triangular pine trees.
- **Titles**: `#ef4444` fill, `#ffffff` stroke (`6px`), `#facc15` underline (`7px`).
- **Subtitles**: `#ffffff` fill, `#000000` stroke (`6px`), bottom-aligned safe zone.
- **Label pills**: `#ffffff` rounded rectangle, `#111827` border (`4px`), `#111827` bold text.
- **Polaroid tape**: `#fde047` with `#a16207` border.
